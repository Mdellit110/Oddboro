# Security

## Report a vulnerability

Report it privately on GitHub: open the repo's **Security** tab and press
**Report a vulnerability**, or go straight to
https://github.com/New-Altitude/Oddboro/security/advisories/new. Only the
maintainers see it.

Please don't open a public issue or pull request for a security problem.

A good report says:

1. What the problem is, and what someone could do with it.
2. How to reproduce it, step by step.
3. Which version you found it in. Oddboro shows its version in Setup, under
   Updates.

## What happens next

We confirm we have your report, look into it, and keep you posted while we
fix it. When the fix ships, we publish an advisory and credit you, unless you
would rather not be named.

## Supported versions

Only the newest release. Every update is required and installs itself, so a
fix reaches every copy of Oddboro and older versions are not patched.

## Scope

In scope:

- The Mac app and the office it runs on your Mac.
- How releases are built, signed, notarized and delivered as updates.
- The website, oddboro.com.

Out of scope:

- Claude Code itself. Report those to Anthropic.
- Outside tools (MCP servers) you connect to your Odds. Report those to
  whoever makes them.
