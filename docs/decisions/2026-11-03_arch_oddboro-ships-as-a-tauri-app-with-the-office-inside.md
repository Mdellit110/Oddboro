- [arch] **Decision (2026-11-03): Oddboro ships as a Tauri shell in Rust that runs the office server on a bundled Node: a signed, notarized Mac app for Apple Silicon, and an AppImage for Linux on x86_64 and arm64, with every update required on both.** A container cannot reach the owner's keychain, Claude Code sign-in or notifications, and one required version means we never support old ones. An AppImage is the one Linux format Tauri's updater can replace in place, so the Linux app keeps that rule. The detail lives in `apps/desktop/CLAUDE.md`; where the code and the owner's office live is `packages/ledger/src/home.ts`. Supersedes the 2026-11-02 ruling that it ships for the Mac only.
