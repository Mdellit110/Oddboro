- [office] **Decision (2026-11-06): every place the office's own code calls out of the computer is declared in `scripts/outbound.ts`, with where it goes, what it sends and whose yes covers it, and `npm run lint` fails when the code and the list differ.** Hard rule 4 promises that nothing leaves the office without the owner's yes, and before this nothing checked it: a new call could be added and no one would see. `scripts/check-outbound.ts` counts the calls in the office's server code, the packages and the desktop app by name, with comments taken out, and fails on a file whose count differs from its entry, an entry whose file has none, and on finding no call at all. A change that adds a call, such as a persona's door to an outside service or an error report, adds its entry in the same change. It matches names in text because the guards take no dependencies, so it cannot see a library's own calls that start from a name it does not list; a new kind of call adds its name to the guard. The list is in `scripts/outbound.ts`, and where to add an entry in the office's `src/lib/server/CLAUDE.md`.
