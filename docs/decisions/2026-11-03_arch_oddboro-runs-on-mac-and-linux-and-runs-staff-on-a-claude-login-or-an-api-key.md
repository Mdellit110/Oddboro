- [arch] **Decision (2026-11-03): Oddboro runs on a Mac and on Linux, and staff run either on the user's own Claude Code login or on an Anthropic API key, the user's choice.** Each system keeps its own login service, secret store and notifications (`packages/ledger/src/platform.ts` and `secrets.ts`): launchd, the Keychain and macOS on a Mac; systemd, the Secret Service keyring and `notify-send` on Linux. Windows is not supported. Two ways to run staff keep the project independent of how Anthropic rules on tools that use a person's Claude subscription. Supersedes the 2026-10-30 ruling that the open-source release starts Mac only.
