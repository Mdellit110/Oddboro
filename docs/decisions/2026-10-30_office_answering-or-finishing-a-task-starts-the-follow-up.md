- [office] **Decision (2026-10-30): the owner answers an ask with Deny, Iterate or Approve. Approve and Iterate each start the staffer at once, and so does marking done a task a staffer gave them (an intake goes back to the staffer that sent it, which then proposes the hire), and the owner hears back only when it fails or needs them, unless they tick "Report when done" (off by default).** An answer is enough to get the work done, so the owner never has to check on it. Deny starts no work. Iterate needs their words, and the reworked ask comes back linked to the one they sent back. Every outcome goes in the ledger and in the Office Manager's daily report. A run cut off by a restart fails rather than run twice, because an approved action may have half happened. Supersedes the 2026-10-30 ruling that only approvals start work. Finished tasks joined the ruling on 2026-10-31, after a finished intake brought no hire back. Code in `apps/office/src/lib/server/follow-ups.ts`.
