- [office] **Decision (2026-11-05): an Odd's panel groups its tabs into three, Chat, Data (Lessons, Storage) and Settings, each an icon and a word, and its name opens an info page laid out as a dashboard that holds In progress and Jobs; supersedes the same day's Chat, Knowledge and Settings ruling.** Five tabs in a row left no room, and a flip card hid most of what an owner wants to see about an Odd. The info page is one scrolling page, most useful first: who it is, what it is doing and what its runs go through; In progress; Jobs, each opened to edit in place, with "+ Add a job" and when it runs next; the job description; stats; its look, with Redraw look and Send to a place. While an Odd has work in progress, a count in a turning ring sits beside its name and opens the page at In progress; the ring turns only while there is work, and not under reduced motion. Chat is the chat alone: no placeholder tabs for what is not built. Storage lists everything in the Odd's own folder as a searchable tree, opened in the office's viewer; it never lists the office's own chat log and session file, an instruction file, a hidden entry or a link, and stops at 5,000 entries. It reads the folder when the tab opens; nothing watches it. Code in `apps/office/src/lib/ui/StaffCard.svelte`, `OddInfo.svelte`, `StorageTab.svelte` and `apps/office/src/lib/server/storage.ts`.
