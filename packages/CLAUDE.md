# packages/

Shared packages, exported as TypeScript source (no build step except the
sprite atlas). Scope `@oddboro/*`.

- [sprites/CLAUDE.md](sprites/CLAUDE.md). The art: `.px` sprites, the palette, the compiler, and the format contract.
- [world/CLAUDE.md](world/CLAUDE.md). Room stamps, floor plans, the world composer, pathfinding, light by hour, and the renderer.
- [ledger/CLAUDE.md](ledger/CLAUDE.md). The office's records in Postgres: Odds (the `staff` table), asks, tasks, reports, access, jobs and the searchable ledger, plus the MCP server Odds run with.
